# gat9 Symlinks Files Store 🔗📦

**gat9-symlinks** — это легкое, безопасное и интуитивно понятное расширение для VS Code, разработанное для изоляции конфигурационных файлов, переменных окружения (.env) и приватных данных от публичных репозиториев без нарушения структуры вашего проекта.

Вместо использования сложных подмодулей Git (Submodules) или ручного шифрования, **gat9** переносит ваши секретные файлы в централизованное защищенное хранилище, оставляя на их месте легковесные символические ссылки (или Junction-точки в Windows).

---

## ✨ Возможности

- **Перенос в один клик (`gat9 Link`)**: Мгновенно перемещает любой секретный файл или папку во внешнее безопасное хранилище. На его месте автоматически создается симлинк.
- **Восстановление в один клик (`gat9 Restore`)**: Безопасно возвращает реальный файл из хранилища обратно в проект, удаляя симлинк.
- **Защита от конфликтов имен**: Автоматически генерирует уникальные имена файлов в хранилище на основе хэша их содержимого (или хэша пути для папок).
- **Двусторонняя визуализация**:
  - 🔗 **Индикатор ссылки**: Подсвечивает виртуальные связанные файлы в вашем проекте значком ссылки и приглушенным цветом. При наведении курсора отображается реальный путь к файлу.
  - 📦 **Индикатор источника**: При просмотре папки безопасного хранилища **gat9-symlinks** сканирует открытый проект и подсвечивает оригинальные файлы значком коробки, показывая в подсказке, какие именно проекты их сейчас используют.
- **Глобальные и локальные конфигурации**: Используйте глобальный файл `~/.gat9-symlinks` для всех проектов или переопределяйте его локально с помощью файла `.gat9-symlinks` в корне конкретного проекта.
- **Кнопка отключения (Kill Switch)**: Можно легко отключить расширение для определенной папки, добавив `"disabled": true` в конфигурационный файл.
- **Безопасное удаление**: Удаляет файлы через стандартную Корзину операционной системы, исключая случайную безвозвратную потерю данных.

## 🚀 Быстрый старт

### 1. Настройка хранилища
Создайте глобальный файл конфигурации в вашей домашней директории (`~/.gat9-symlinks`) или локальный файл в корне вашего проекта (`.gat9-symlinks`).

Формат файла (**JSON**):
```json
{
  "version": "1.0",
  "storePath": "D:/MySecureStorage/project-secrets"
}
```

*Примечание: Если вы хотите временно отключить расширение для конкретной папки, просто добавьте `"disabled": true` или `"ignore": true` в локальный файл `.gat9-symlinks`.*

### 2. Перенос секретов в хранилище
1. Нажмите правой кнопкой мыши на любой секретный файл или папку (например, `.env`, `config/settings.json`) в проводнике VS Code.
2. Выберите пункт **gat9 Link**.
3. Файл будет безопасно перемещен, а на его месте появится симлинк со значком `🔗`.

### 3. Восстановление файлов
1. Нажмите правой кнопкой мыши на залинкованный файл или папку в проводнике.
2. Выберите пункт **gat9 Restore**.
3. Симлинк будет удален, а оригинальный файл вернется на свое прежнее место.

## ⚙️ Настройки расширения

Данное расширение добавляет следующие параметры в настройки VS Code:

* `gat9-symlinks.enableBackups`: (Boolean, по умолчанию: `true`) Создавать резервные копии файлов перед перезаписью во время операций.
* `gat9-symlinks.globalConfigPath`: (String, по умолчанию: `"~/.gat9-symlinks"`) Задает кастомный путь к глобальному файлу конфигурации.

---

## 🛑 Требования для Windows 11

Поскольку **gat9-symlinks** использует системные символические ссылки и точки соединения (junction points) Windows:
* **Требуется режим разработчика**: Обязательно убедитесь, что в вашей Windows 11 включен **Режим разработчика** (*Параметры -> Конфиденциальность и защита -> Для разработчиков -> Режим разработчика -> Вкл*). Это позволит расширению создавать симлинки без необходимости запуска VS Code от имени Администратора.
